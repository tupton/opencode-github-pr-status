# GitHub PR Status

Shows the current session's branch pull request in the OpenCode terminal.

## Language

**Pull request indicator**:
The prompt-footer display of the current branch's pull request number and status color. It is empty when there is no pull request to display.

**Last known pull request**:
The most recently retrieved pull request for a branch when a subsequent refresh fails. It remains eligible for display and opening only while that branch is known to be current.
