# Domain docs

This is a single-context repo. Read the root `CONTEXT.md` before exploring domain code, and read relevant decisions in `docs/adr/` before changing an area.

These files do not exist yet. Proceed when they are absent; create them when domain terms or decisions need recording.

Use terms defined in `CONTEXT.md` in issues, proposals, and tests. If a proposed change conflicts with an ADR, identify that decision and explain why it needs another look.
